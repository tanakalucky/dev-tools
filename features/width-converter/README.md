# width-converter

テキストの全角・半角を相互に変換するツール。ルートは `/width-converter`(`app/width-converter/page.tsx`)。処理はブラウザ内だけで行い、送信・保存・追跡はしない。

## できること

- 変換: 方向(全角 → 半角 / 半角 → 全角、初期値は全角 → 半角)を選び、「変換する」を押したときだけ実行する。入力中や方向の切り替えでは変換せず、結果は次に押すまで前回のまま残る。
- コピー: 変換結果をクリップボードへコピーする。結果が空のときは押せない。

履歴、永続化、ファイル出力、変換対象の絞り込みは扱わない。

## 構成

- `lib/convert-width.ts` - 純粋な処理 `convertWidth(text, direction)`(React / DOM に依存しない)。テストは隣の `convert-width.test.ts`。
- `components/width-converter.tsx` - 画面(Client Component)。shadcn の `Button` と `Textarea` を使う。方向の選択は `components/ui/` に該当部品がないためネイティブの `select` を同じトークンで整えている。

## 変換規則

- 対応表は UnicodeData.txt の互換分解 `<wide>`(104 行)と `<narrow>`(122 行)に一致する。両方向とも同じ表を使う。FF00 番台の欠番はそのまま欠番で、対応のない文字は変換せずに残す。
  - 全角 → 半角: 全角 ASCII(U+FF01〜FF5E)、U+3000 → U+0020、`｟｠`、通貨・記号(`￠￡￢￣￤￥￦`)。
  - 半角 → 全角: 半角カタカナと句読点・長音(`｡｢｣､･ｰ` など)、ハングル互換字母、矢印・罫線・図形(`￨￩￪￫￬￭￮`)。
- `￥`(U+FFE5)と `＼`(U+FF3C)は別の文字で、それぞれ `¥`(U+00A5)と `\`(U+005C)に対応する。
- 濁点・半濁点: 半角の「基底 + ﾞ/ﾟ」は、全角に合成形があれば 1 字にまとめる(`ｶﾞ` ⇔ `ガ`、`ﾊﾟ` ⇔ `パ`、`ｳﾞ` ⇔ `ヴ`、`ﾜﾞ` ⇔ `ヷ`、`ｦﾞ` ⇔ `ヺ`)。合成形がない組み合わせと単独の `ﾞ` `ﾟ` は、結合文字 U+3099 / U+309A へ直接対応する(逆向きも同じ)。スペース付きの `゛` `゜`(U+309B / U+309C)は変換しない。
- 入力全体に NFKC / NFC は使わない。丸数字、単位記号、幅と無関係な分解済みの並びなどは、そのまま残る。NFC は対応表を作るときの「基底 + 結合記号」の 2 字にだけ使う。
