# json-formatter

JSON を 2 スペースインデントで整形するツール。ルートは `/json`(`app/json/page.tsx`)。入力はブラウザ内だけで処理し、送信・保存・追跡はしない。

## できること

- 整形: 「整形する」ボタンを押したときだけ実行する(貼り付け時には実行しない)。インデントは 2 スペース固定。
- 結果をコピー: 整形に成功した結果だけをクリップボードへコピーする。
- クリア: 入力・出力・メッセージを消す。

minify、validate 専用モード、履歴、永続化、ファイル入出力、インデント選択は扱わない。

## 構成

- `lib/format-json.ts` - 純粋な整形処理 `formatJson(input)`(React / DOM に依存しない)。テストは隣の `format-json.test.ts`。
- `components/json-formatter.tsx` - 画面(Client Component)。shadcn の `Button` と `Textarea` を使う。

## 解析規則

1. まず入力をそのまま `JSON.parse` する。成功すればそれを整形する(外側が JSON 文字列でも展開しない)。
2. 失敗したときだけ、ターミナル表示由来の形を調べる。先頭の非空白文字が `{` または `[` で、入力に `"` が 1 つ以上あり、そのすべてが直前に `\` を伴っている(元の `"` がそれぞれ `\"` になった)場合に限り、各 `"` の直前の `\` を 1 つだけ取り除く。他の `\`(文字列中のリテラルの `\` や `\n` など)は変えない。
3. 取り除いた文字列を 1 回だけ `JSON.parse` する。失敗、または 2 の形でなければ、元の入力に対するエラーを表示する。入力は変更しない。

再帰的なデコード、外側の文字列の展開、その他の推測による修復はしない。`\` が付いていない `"` が混ざる入力や、1 回の復元後も有効な JSON にならない入力はエラーになる。

## 注意

- 整形後は `JSON.stringify` を通すため、数値は JavaScript の `Number` で表せる精度になる。非常に大きな指数は `null` になり、`-0` は `0` になる。重複キーは後勝ちになり、整数風のキーは並び順が変わることがある。
