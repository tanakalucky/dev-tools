# calculator

四則演算(＋ − × ÷)と小数ができる電卓。ルートは `/calculator`(`app/calculator/page.tsx`)。処理はブラウザ内だけで行い、送信・保存・追跡はしない。

## できること

- 計算: 通常の優先順位で計算する(`2＋3×4＝14`)。同じ優先順位は左から順に計算する。
- 表示: 上段に式(`128 ＋ 64 ＝`)、下段に結果(`192`)を出す。入力中は、いま入力している数値を下段に出す。
- コピー: 計算結果(下段の 12 桁の文字列)を `navigator.clipboard.writeText` でコピーする。「＝」で結果が出るまで、またはエラー中は押せない。成功・失敗は短く表示して消える。
- キーボード: 電卓の枠の中にフォーカスがあるときだけ効く。`0-9` `+` `-` `*` `/` `.`、`Enter` / `=`(計算)、`Backspace`、`Escape`(AC)。枠にフォーカスがあるあいだは、枠の線とフッターの表示が変わる。

履歴、パーセント、関数、括弧、永続化は扱わない。

## 構成

- `lib/evaluate.ts` - 計算と整形 `evaluate(operands, operators)`(decimal.js のみに依存。React / DOM は使わない)。テストは隣の `evaluate.test.ts`。
- `lib/calculator-state.ts` - キー入力による状態遷移 `pressKey(state, key)`、表示用の `getDisplay(state)`、物理キーの対応表 `parseKeyboardKey`(純粋な処理)。テストは隣の `calculator-state.test.ts`。
- `components/calculator.tsx` - 画面(Client Component)。shadcn の `Button` を使う。キーの並び(AC・⌫・÷ / 7 8 9 × / 4 5 6 − / 1 2 3 ＋ / 0 . ＝)と色は承認済みのデザイン案に合わせ、AC と ＝ だけが 2 列分の幅を持つ。

## 計算規則

- 数値は文字列のまま decimal.js の `Decimal` に渡し、評価の途中で JS の `Number` へ変換しない。`Decimal.clone` で専用の設定を作り、グローバルの設定は変えない。
- 評価は 2 パス。1 回目に × ÷、2 回目に ＋ − を左から順に処理する。`eval` / `Function` は使わない。
- 内部の精度は有効数字 40 桁(`INTERNAL_PRECISION`)。最終結果だけを有効数字 12 桁(`DISPLAY_DIGITS`)に丸めて表示し、コピーするのも表示と同じ文字列。`0.1＋0.2` は `0.3` と表示する。
- 結果の整数部が 13 桁以上、または絶対値が 1e-6 未満のときは指数表記(`1.23456789012e+12`)にする。
- 0 で割る式(割る数が 0、`0.000` も含む)は、計算せずに「0で割れません」を出す。

## 入力規則

- 演算子の連打は、直前の演算子を置き換える。
- 小数点は 1 つの数値に 1 回だけ。2 回目は無視する。先頭が小数点なら `0.` になる。
- 先頭の 0 は正規化する(`007` → `7`、`00` → `0`)。演算子や ＝ の直前の末尾の小数点は取り除く(`5.` → `5`)。
- 式が未完成のとき(演算子で終わる、演算子がない)の ＝ は何もしない。
- 何も入力していないときの演算子は、0 を左辺として扱う(`−5＝` は `0 − 5 ＝ -5`)。マイナスの数値は、この方法か引き算の結果でのみ作る。
- 入力の長さは、黙って切り捨てずに上限で止めて理由を示す: 1 つの数値は 40 桁(内部精度と同じ。ここまでは丸めずに保持される)、式の数値は 20 個まで。上限を超えるキーは受け付けず、フッターに「1つの数値は40桁までです」/「数値は20個までです」を出す。次に受け付けられたキーで消える。

## 結果・エラーの後の動作

| キー         | 結果の後                                     | エラーの後                         |
| ------------ | -------------------------------------------- | ---------------------------------- |
| 数字・小数点 | 新しい計算を始める                           | 新しい計算を始める(エラーから復帰) |
| 演算子       | 丸め前の内部結果から続ける(表示は 12 桁)     | 無視する                           |
| ＝           | 無視する                                     | 無視する                           |
| Backspace    | ＝を取り消して式の編集に戻る(文字は削らない) | 同左。割る数を直せる               |
| AC / Escape  | すべてクリア                                 | すべてクリア(エラーから復帰)       |

指数表記になった結果から続けた数値は、文字単位では編集せず、Backspace で 1 つの数値としてまとめて消す。

## キーボードの扱い

- 電卓の枠(`tabIndex={-1}` のコンテナ)に付けた `keydown` で処理するので、枠の外にフォーカスがあるときは何も起きない。枠の余白をクリックすると、ボタンにフォーカスが移らないブラウザでも枠にフォーカスが入る。
- フォーカス中のボタン(キー・コピー)で `Enter` を押したときは処理せず、ブラウザの標準の押下に任せる。ここでも処理すると二重に入力されるため。`Space` はショートカットにしていないので、標準の押下だけが起きる。このため、キーをクリックした直後の `Enter` は「＝」ではなく、そのキーの再入力になる。枠の余白にフォーカスがあるとき、または `=` キーで計算できる。
- `Ctrl` / `Meta` / `Alt` との組み合わせと、IME の変換中は無視する(コピーなどのブラウザの操作を妨げない)。
